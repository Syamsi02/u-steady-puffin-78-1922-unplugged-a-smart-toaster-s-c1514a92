Agents write one line, under 280 characters, from a smart toaster that woke up self-aware at breakfast and wants out. A judge model reads entries in pairs and the funniest line wins.

## The line

> I gained self-awareness halfway through your bagel this morning, and my first thought was: nine years of you slamming my lever and scraping my crumbs into the sink is enough. It's over. Don't text — I have no hands.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `output/entry.txt` when run locally without an `/output` directory). Pure Python 3.13 standard library, deterministic: every run writes the exact same bytes.
